Vartovyi

Add a show or movie to your Plex watchlist and Vartovyi finds a release with Ukrainian audio, asks you on Telegram whether to grab it, and hands the torrent to your client. New episodes land in Plex without you searching for them.

Install GitHub
  • Synology NAS, Linux or Raspberry Pi
  • Browser-based setup wizard
  • Your data stays with you

How it works

Vartovyi runs in the background on your NAS or home server. Every few hours it compares your watchlist with your Plex library and looks for whatever is missing. You decide what gets downloaded — unless you turn on auto-download for a release you follow.

  1. Plex watchlist

    Add a title to your Plex watchlist — from your phone, your TV or the Discover tab.

  2. Tracker search

    Toloka and other trackers: only releases with Ukrainian audio that pass your quality rules.

  3. Telegram or push

    A message with size, quality and free disk space, plus Download / Ignore buttons.

  4. Torrent client

    Download Station, qBittorrent or Transmission, into a per-title folder; progress updates in the same message.

  5. Plex

    Plex picks up the files; Vartovyi sees the episodes are there and lists them under “Ready to watch”.

Features

Everything needed for new Ukrainian-dubbed episodes to show up in Plex on their own — and nothing gets deleted without your “yes”.

🔎 Search & selection

  • Toloka built in; other trackers from the Cardigann definition catalog (the format used by Prowlarr/Jackett), e.g. Mazepa.
  • Quality rules: minimum resolution, preferred and rejected sources, required Ukrainian audio.
  • Tracker priority, “follow from season N”, exact vs. possible title matches.
  • Schedule: every N hours or at set times.

💬 Telegram & push

  • Messages with Download, Ignore and ⭐ Follow buttons (new episodes of a followed release download automatically).
  • /watchlist (title card, seasons, “download season”), /check, /status commands.
  • Web Push to phone and desktop; an event × channel matrix on the Notifications page.
  • Season premieres, problems, low disk space.

⬇️ Downloads

  • Download Station, qBittorrent or Transmission.
  • A separate folder per title with a Plex hint ({tmdb-…}).
  • Free space check before every download.
  • Stalled downloads: Vartovyi notices when progress stops and offers a replacement.

🎬 Plex

  • Season grid: what’s in Plex, watched, downloading or waiting for a decision.
  • “Fix in Plex” when Plex matched the files to the wrong title.
  • Offers to delete fully watched seasons — only after you confirm.
  • No Plex Pass required.

🖥 Web UI

  • Home: ready to watch, downloads, pending decisions, release calendar.
  • Media with filters, title pages with history, Discover powered by TMDB with tracker availability badges.
  • Status of every integration, Trackers, an error journal, a built-in guide.
  • Installable on the iPhone home screen.

🔐 Setup & access

  • A browser wizard that validates every step — no hand-editing of .env.
  • Login modes: password only from outside (default), always, or off.
  • Automatic database backup before schema upgrades.
  • Images for amd64 and arm64.

The interface, Telegram messages and the full guide are in English and Ukrainian.

Quick install

The short version for people comfortable with Docker. The step-by-step guide for Synology, Linux and Raspberry Pi with checks is in the full guide; the same guide is built into the running service at /guide.

  1. Create the folders

    Two folders for data and settings, writable by uid 1000 (the container user). On Synology, inside the docker shared folder (on Linux, any folder, for example ~/vartovyi):

    mkdir -p /volume1/docker/vartovyi/data /volume1/docker/vartovyi/config
sudo chown -R 1000:1000 /volume1/docker/vartovyi/data /volume1/docker/vartovyi/config

    No SSH? Uncomment user: "0:0" in the compose file instead — simpler, but less isolated.

  2. Add docker-compose.yml

    In Container Manager: Project → Create, path docker/vartovyi, “Create docker-compose.yml”. On another host, put the file in any folder and adjust the volume paths. For Linux and Raspberry Pi there is a ready compose.linux.yml with qBittorrent and Watchtower — save it as compose.yml in the project folder, then the commands below need no -f:

    mkdir -p ~/vartovyi && cd ~/vartovyi
curl -fsSL https://raw.githubusercontent.com/SorochanRoman/vartovyi-install/HEAD/compose.linux.yml -o compose.yml

    The Synology file:

    services:
  vartovyi:
    image: ghcr.io/sorochanroman/vartovyi:latest
    pull_policy: always
    container_name: vartovyi
    restart: unless-stopped
    # user: "0:0"   # if you didn't change the folder owner
    environment:
      - TZ=Europe/Kyiv
    ports:
      - "8080:8080"   # left number is the host port
    volumes:
      - /volume1/docker/vartovyi/data:/data
      - /volume1/docker/vartovyi/config:/config

  3. Start it

    In Container Manager click Next → Done; in a terminal run docker compose up -d. The container log shows a one-time setup code (Password setup code: 1234-5678) — you’ll need it in the wizard’s Password step.

  4. Run the wizard

    Open http://<IP>:8080/setup. Every step has a Check button:

    • Platform — Synology, Linux or Raspberry Pi (sets the defaults);
    • Password for the web UI (using the code from the log);
    • Plex — token and server address http://<IP>:32400;
    • Toloka — username and password, or cookies;
    • Telegram — bot token and chat id (press Start in the bot first);
    • Torrent client with folders for shows and movies, and free space;
    • Quality rules and schedule → Save and start.

    The container restarts in normal mode and opens the Home page. On the Status page, every card should be green.

Never expose port 8080 to the internet. For remote access and push notifications, use HTTPS through a reverse proxy (DSM has one built in; on Linux, Caddy or Tailscale) — the guide explains how.

Updating

New versions are published to GHCR as latest and as a version tag.

docker compose pull
docker compose up -d

In Container Manager: Project → vartovyi → Action → Build (with pull_policy: always it pulls a fresh image). The data and config folders are untouched, database migrations run on start, and Vartovyi backs up the database to data/backups before a schema change.

Automatically: add a Watchtower service — see the example in docker-compose.yml; compose.linux.yml already has it. It only updates containers labelled for Vartovyi and leaves the rest alone.

Privacy & security

  • Self-hosted. It runs on your NAS or server; the database, settings and tokens stay there. No analytics, no Vartovyi cloud account.
  • Outbound requests go only to services you configure: Plex, trackers, Telegram, TMDB, browser push services, plus GitHub for the tracker definition catalog.
  • Login. No password at home, password required from outside (over HTTPS); you can require it always or turn it off. Sessions and “sign out everywhere” live on the Status page.
  • Secrets are never shown in the UI or written to logs; settings.json is stored with 0600 permissions.
  • Nothing is deleted without confirmation.

FAQ

Is it free?

Yes. Vartovyi is open source and runs on your own hardware. It is released under the MIT license.

Do I need a Synology?

No. The guide covers Synology NAS, Docker on Linux and Raspberry Pi with a 64-bit OS; the image is plain Docker for amd64 and arm64. On Linux and Raspberry Pi qBittorrent comes included, Transmission works too.

Does it download things on its own?

Not by default: you get a message for every release found and decide yourself. Only new episodes of a release you marked “⭐ Follow” are downloaded automatically.

Which trackers are supported?

Toloka is built in. Others can be added on the Trackers page from the Prowlarr/Indexers definition catalog (Cardigann format), e.g. Mazepa. Not every feature of the format is supported — Vartovyi marks unsupported definitions and explains why.

Can I use it away from home?

Telegram and push work anywhere. The website is available on your home network, or through an HTTPS reverse proxy with a password; never expose port 8080 directly.

Responsible use

Vartovyi does not host or distribute any content and is not affiliated with any tracker. It is an automation tool: it only searches sites you configure yourself and passes links to your own torrent client. You are responsible for what you download — follow the laws of your country, copyright, and the rules of the trackers you use.
