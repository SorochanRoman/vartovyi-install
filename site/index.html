Vartovyi

Додаєте серіал чи фільм у watchlist Plex — Vartovyi сам знаходить роздачу з українською озвучкою, питає в Telegram «качати?» і передає торент у ваш клієнт. Нова серія з’являється в Plex без ручного пошуку.

Встановити GitHub
  • Synology NAS, Linux або Raspberry Pi
  • Майстер налаштування в браузері
  • Дані лишаються у вас

Як це працює

Vartovyi працює у фоні на вашому NAS чи домашньому сервері: раз на кілька годин звіряє watchlist із бібліотекою Plex і шукає те, чого бракує. Рішення «качати чи ні» лишається за вами, якщо не ввімкнете автозавантаження для улюбленої роздачі.

  1. Plex watchlist

    Ви додаєте тайтл у watchlist Plex — з телефона, телевізора чи з вкладки «Підбірки».

  2. Пошук на трекерах

    Toloka та інші трекери: лише роздачі з українською озвучкою, що проходять ваші правила якості.

  3. Telegram або push

    Повідомлення з розміром, якістю й вільним місцем і кнопками «Завантажити» / «Ігнорувати».

  4. Торент-клієнт

    Download Station, qBittorrent або Transmission — в окрему папку тайтлу; статус оновлюється в тому ж повідомленні.

  5. Plex

    Plex підхоплює файли, а Vartovyi бачить, що серії вже є, і показує їх у «Готове до перегляду».

Можливості

Усе, що потрібно, щоб нові серії з українською озвучкою з’являлися в Plex самі, — і нічого не видалялося без вашого «так».

Швидке встановлення

Коротка версія для тих, хто знайомий з Docker. Покрокова інструкція для Synology, Linux і Raspberry Pi з перевірками — у повній інструкції; та сама інструкція є в запущеному сервісі на сторінці /guide («Інструкція» у меню).

  1. Створіть папки

    Дві папки для даних і налаштувань, доступні на запис користувачу з uid 1000 (від нього працює контейнер). На Synology — у спільній папці docker (на Linux — будь-яка папка, наприклад ~/vartovyi):

    mkdir -p /volume1/docker/vartovyi/data /volume1/docker/vartovyi/config
sudo chown -R 1000:1000 /volume1/docker/vartovyi/data /volume1/docker/vartovyi/config

    Без SSH можна натомість розкоментувати user: "0:0" у compose — простіше, але менше ізоляції.

  2. Додайте docker-compose.yml

    У Container Manager: Проєкт → Створити, шлях docker/vartovyi, «Створити docker-compose.yml». На іншому сервері — файл у будь-якій папці (шляхи томів змініть на свої). На Linux і Raspberry Pi є готовий compose.linux.yml з qBittorrent і Watchtower — збережіть його в папці проєкту як compose.yml, тоді командам нижче не потрібен -f:

    mkdir -p ~/vartovyi && cd ~/vartovyi
curl -fsSL https://raw.githubusercontent.com/SorochanRoman/vartovyi-install/HEAD/compose.linux.yml -o compose.yml

    Файл для Synology:

    services:
  vartovyi:
    image: ghcr.io/sorochanroman/vartovyi:latest
    pull_policy: always
    container_name: vartovyi
    restart: unless-stopped
    # user: "0:0"   # якщо не змінювали власника папок
    environment:
      - TZ=Europe/Kyiv
    ports:
      - "8080:8080"   # ліве число — порт на хості
    volumes:
      - /volume1/docker/vartovyi/data:/data
      - /volume1/docker/vartovyi/config:/config

  3. Запустіть

    У Container Manager — Далі → Готово; у терміналі — docker compose up -d. У журналі контейнера з’явиться рядок Код для створення пароля: 1234-5678 — він знадобиться на кроці майстра «Пароль».

  4. Пройдіть майстер

    Відкрийте http://<IP>:8080/setup. Кожен крок має кнопку Перевірити:

    • Платформа — Synology, Linux або Raspberry Pi (задає типові значення);
    • Пароль вебінтерфейсу (з кодом із журналу);
    • Plex — токен і адреса сервера http://<IP>:32400;
    • Toloka — логін і пароль або кукі;
    • Telegram — токен бота і chat id (спершу натисніть Start у боті);
    • Торент-клієнт і папки для серіалів та фільмів, вільне місце;
    • Правила якості і розклад → Зберегти і запустити.

    Контейнер перезапуститься в робочому режимі, і відкриється «Головна». На сторінці «Стан системи» всі картки мають бути зеленими.

Не відкривайте порт 8080 в інтернет. Для доступу ззовні й push-сповіщень використовуйте HTTPS через зворотний проксі (у DSM — вбудований, на Linux — Caddy або Tailscale) — як саме, описано в інструкції.

Оновлення

Нові версії публікуються в GHCR з тегом latest і номером версії.

docker compose pull
docker compose up -d

У Container Manager: Проєкт → vartovyi → Дія → Зібрати (з pull_policy: always образ стягується свіжий). Папки data і config не змінюються, міграції бази виконуються самі, а перед зміною схеми Vartovyi робить копію в data/backups.

Автоматично: додайте сервіс Watchtower — приклад є в docker-compose.yml, а в compose.linux.yml він уже є. Він оновлює лише контейнери з позначкою Vartovyi і не чіпає решту.

Приватність і безпека

  • Self-hosted. Сервіс працює на вашому NAS чи сервері; база, налаштування й токени лишаються там. Жодної аналітики чи хмарного акаунту Vartovyi немає.
  • Зовнішні запити — лише до сервісів, які ви налаштували: Plex, трекери, Telegram, TMDB, служби push браузерів, а також GitHub для каталогу описів трекерів.
  • Вхід. Удома — без пароля, ззовні (через HTTPS) — з паролем; можна вимагати пароль завжди або вимкнути вхід. Сесії й вихід на всіх пристроях — на сторінці «Стан».
  • Секрети не показуються у вебінтерфейсі й не пишуться в журнал; settings.json зберігається з правами 0600.
  • Нічого не видаляється без підтвердження.

Питання

Це безкоштовно?

Так. Vartovyi — проєкт з відкритим кодом, ви запускаєте його на власному обладнанні. Код поширюється під ліцензією MIT.

Чи потрібен Synology?

Ні. Інструкція є для Synology NAS, Docker на Linux і Raspberry Pi з 64-бітною ОС; образ — звичайний Docker для amd64 і arm64. На Linux і Raspberry Pi qBittorrent іде в комплекті, підійде й Transmission.

Чи завантажує він щось сам, без мене?

Типово — ні: про кожну знайдену роздачу ви отримуєте повідомлення й вирішуєте самі. Автоматично качаються лише нові серії роздачі, яку ви позначили «⭐ Стежити».

Які трекери підтримуються?

Toloka вбудована. Інші можна додати на сторінці «Трекери» з каталогу описів Prowlarr/Indexers (формат Cardigann), наприклад Mazepa. Підтримуються не всі можливості формату — непідтримувані описи Vartovyi позначає з поясненням причини.

Чи можна користуватися поза домом?

Telegram і push працюють будь-де. Сайт — у домашній мережі або через HTTPS-проксі з паролем; відкривати порт 8080 в інтернет не можна.

Відповідальне використання

Vartovyi не розміщує й не роздає жодного контенту і не пов’язаний із жодним трекером. Це інструмент автоматизації: він лише шукає на сайтах, які ви самі налаштували, і передає посилання вашому торент-клієнту. Ви відповідаєте за те, що завантажуєте: дотримуйтесь законодавства своєї країни, авторських прав і правил трекерів, якими користуєтесь.
